## 🚀 About the Project

**Nois** is a scalable e-commerce system where users can design and purchase custom clothing like t-shirts and hoodies.

Built with **Onion Architecture**, it focuses on clean separation of concerns, maintainability, and production-ready backend design.

---

## ✨ Key Highlights

- Product-based e-commerce system for clothing items
- Secure payments via Stripe  
- Cloud-based media handling  
- Robust validation & global error handling  
- Fully containerized with Docker
